# Addis Market Order Summary

## 📌 Project Overview

This project is a small JavaScript order summary module for **Addis Market**.

It takes an array of customer orders, calculates the total price of each order, adds **15% VAT**, identifies orders above **500 ETB**, and calculates the grand total.

The project demonstrates the use of:

- JavaScript modules
- `map()`
- `filter()`
- `reduce()`
- Destructuring
- Spread syntax
- Default parameters
- Functions
- `forEach()`

---

## 📁 Project Files

### `orders.js`

Contains the sample Addis Market orders.

Each order has:

- An `id`
- A list of items
- Each item has a `name`, `price`, and `qty`
