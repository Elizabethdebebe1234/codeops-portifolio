# Addis Market Shopping List

## Week-2 Interactive DOM Application

Addis Market is a single-page interactive shopping list application built using HTML, CSS, and JavaScript.

The application allows users to add shopping items with their name and price in ETB, mark items as bought, delete items, and view a live running total.

## Features

- Add shopping items using a form
- Validate item name and price
- Prevent default form submission
- Dynamically create list items using `createElement()`
- Add elements using `append()`
- Mark items as bought
- Delete items
- Use event delegation for list interactions
- Display a live running total in ETB
- Responsive design for smaller screens
