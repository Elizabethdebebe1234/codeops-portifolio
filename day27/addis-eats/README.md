# Addis Eats React

Addis Eats is a static Ethiopian food menu built with React and Vite.

## Features

- Reusable Header component
- Reusable Dish component
- Props for dish names and prices
- Menu rendered from an array using map()
- Unique keys for each dish
- Ethiopian food prices displayed in ETB
- Responsive layout

## Technologies

- React
- Vite
- JavaScript
- CSS
